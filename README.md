# IProFixer

IProFixer is a bilingual Hospitality Asset Lifecycle Care platform for UAE and KSA.

This repository is the canonical implementation workspace for the public website, content and growth console, commercial workspace, operations and finance workspace, and future client portal.

## Product direction

- Buyer-facing launch category: **Hospitality Asset Care**
- Strategic category: **Hospitality Asset Lifecycle Care**
- Commercial entry point: **Silverware, Flatware & Hollowware Restoration**
- Experience baseline: light mode only, English and Arabic with true RTL, responsive PWA
- Architecture baseline: modular Laravel monolith with bounded product surfaces

The authoritative planning documents are stored under `source_of_truth/`.
