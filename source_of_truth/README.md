# IProFixer Source of Truth

This directory contains the canonical product, design, requirements, and delivery governance documents for IProFixer.

## Authority order

1. `MASTER_BLUEPRINT_V2.md`
2. `SRS.md`
3. `UI_UX_SPECIFICATION.md`
4. `IMPLEMENTATION_PLAN.md`
5. Approved visual references

Implementation must not contradict a higher-authority document without first updating the canonical source of truth through review.

## Non-negotiable product laws

- Light mode only.
- English and Arabic are first-class, with true RTL behavior.
- The approved homepage visual is the visual source of truth for R1.
- Public claims must be supported by evidence.
- Subcontracted or specialist-network delivery must not be misrepresented as in-house execution.
- AI is introduced only where it has a verified operational purpose.
- Website, CMS, commercial, operations/finance, and client portal are bounded product surfaces even when implemented in one Laravel codebase.
